Select to Autocomplete

A redesigned location selector: a plain <select> becomes a text field that you can type into, with synonyms, alternative spellings, loose matching and prioritised results.

Based on Redesigning The Country Selector (Smashing Magazine) by the Baymard Institute.

1. Live demo: country selector

Click into the field and start typing. The dropdown narrows as you type, and the best match is highlighted so you can press Enter or Tab to pick it. The original <select name="Country"> is still in the form, hidden, and is what gets submitted.

Try a country code, a native name or a nickname, not only the English name.

    2. How it works

    1. Start from a normal <select>. Each <option> can carry two extra attributes: data-alternative-spellings (a space-separated list of synonyms, codes, native names and common misspellings) and data-relevancy-booster (a multiplier that pushes popular entries up the list).
    2. The plugin hides the select and inserts a text field right after it. Attributes such as class, placeholder and autocomplete are copied across, so the text field styles like the rest of your form. Options with an empty value (the "Select Country" prompt) are dropped from the suggestions.
    3. Every option becomes a "matches" string: its label plus its alternative spellings. For Germany that is Germany DE Bundesrepublik Deutschland, which is why typing deutschland finds it.
    4. Loose matching. The query is split on spaces. An option is shown only when every query word appears somewhere in its matches string (case-insensitive, anywhere in a word). That is why south korea narrows to one result while korea shows both Koreas.
    5. Relevancy scoring. Each shown option gets a score, and the list is sorted by score, then alphabetically:

    score = (partial matches × 1 + (5 if a word starts with the query)) × booster

    Typing in partially matches dozens of countries, but India starts with "in" and has a booster of 3, so it lands at the top. Åland Islands, boosted at 0.5, stays near the bottom even when it matches.

    1. Selection is synced back. Picking a suggestion, tabbing away with a full match typed, or submitting the form writes the option's real value into the hidden select and fires its change event. Text that matches nothing resets the field to the last valid selection, so the form can never submit an invalid country.

    3. It works for any location list

    Nothing in the plugin is country-specific. Here the same call is applied to a list of cities, using alternative spellings for former names, local names and abbreviations.

    Note the option values here are airport codes, so the form submits City=NYC while the user sees "New York".

      4. Usage

      Include jQuery, jQuery UI (autocomplete widget) and the plugin, mark up a select, and call selectToAutocomplete() on it.

      <script src="jquery-1.11.1.min.js"></script>
<script src="jquery-ui.min.js"></script>
<script src="jquery.select-to-autocomplete.js"></script>
<link rel="stylesheet" href="jquery-ui.css">

<select name="Country" id="country-selector">
  <option value="">Select Country</option>
  <option value="Germany"
          data-alternative-spellings="DE Bundesrepublik Deutschland"
          data-relevancy-booster="3">Germany</option>
  <option value="Netherlands"
          data-alternative-spellings="NL Holland Nederland"
          data-relevancy-booster="1.5">Netherlands</option>
  ...
</select>

<script>
  $(function () {
    $('#country-selector').selectToAutocomplete();
  });
</script>

      Options are passed as an object: $('select').selectToAutocomplete({ 'relevancy-sorting': false }). Note that settings are shared by every selector initialised on the page, so pass the same options to each call.
